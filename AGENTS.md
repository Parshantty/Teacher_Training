# Teacher Training development

Follow the supplied role guidance in `docs/agents/` when working as React developer, tester, reviewer, product manager, or DevOps engineer. The original workspace roles were read before implementation and retained here for future sessions.

The user selected React, TypeScript, MUI, and Zustand. MUI's Emotion dependencies are required for styling. Do not introduce another UI kit, state library, routing library, or API integration unless the user changes scope. The React role's TanStack Query guidance applies only if APIs are later authorized.

Keep strict types and accessible controls. Prefer cohesive component files up to 150 lines. Use synthetic data and explicit demo labels. Never persist passwords, OTPs, or mobile numbers. Client-side role views are demo UX, not a production authorization boundary.

Run `npm run typecheck`, `npm test`, and `npm run build` for meaningful application changes. On Windows use `npm.cmd` if PowerShell blocks npm.ps1. Local npm cache is `.npm-cache`. Keep the lockfile in sync.

Preserve Git history, the GitHub `origin`, the public Site identity in `.openai/hosting.json`, and hash-route compatibility. The user authorized initial public publication; preserve the current audience on later updates. Never claim GitHub or Sites publication without a confirmed deployment result.
